# Lingo

英語・日本語・中国語の間でページを翻訳する、個人用のChrome拡張です。自分のOpenAI APIキーを使い、選んだ言語の原文とページタイトルを設定したAPIに送ります。

## Chromeで使う

1. Chromeのアドレスバーに `chrome://extensions` を入力し、「デベロッパーモード」をオンにします。
2. 「パッケージ化されていない拡張機能を読み込む」から、Lingoの manifest.json が入ったフォルダを選びます。ソースのルートをそのまま読み込めます。
3. りんごのアイコンをクリックしてLingoを開き、初回はAPIキーを保存します。翻訳元と翻訳先を選び、「翻訳」で今のページを翻訳します。「対訳」で原文と訳文を、「全訳」で訳文を表示します。「原文」で元の表示に切り替えられます。「このサイトを自動翻訳」をオンにすると同じホストのページを自動翻訳します。赤い実の塗りつぶしはオン、輪郭はオフです。

キーは端末内に保存され、Chromeの再起動後も使えます。保存領域は暗号化されないため、Chromeのプロファイルを読み取れる人やソフトウェアはキーにアクセスできます。送信先を変更すると、その運営者にもキーと本文が渡ります。[設定と表示の切り替え](./docs/manuals/index.md) · [データと権限](./docs/index.md)

## 開発と確認

Node.js 24 と pnpm 11.25.0 を使い、ルートで実行します。

```sh
pnpm install --frozen-lockfile
pnpm check
```

`pnpm check` は文書、未使用コード、書式、lint、拡張のJavaScriptの型、単体テストを検査し、拡張の実行ファイルを dist にまとめます。すでにルートをChromeに読み込んでいる場合は、その拡張の再読み込みボタンを押してください。同じフォルダを使うと保存済み設定を引き継げます。

画面・API・権限・配布内容の変更では、続けてブラウザーテストを実行します。

```sh
pnpm exec playwright install chromium
pnpm test:e2e
```

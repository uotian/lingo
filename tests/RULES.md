# テストの規約

[共通規約](../RULES.md)と[拡張の構成](../docs/index.md)を確認してから変更する。

- ユニットは tests/src/unit に置き、入力と結果、拒否すべき操作、失敗後の設定を検証する。文書などのチェッカーは正常例と違反例を持つ。
- E2Eは tests/src/e2e に置き、配布用ファイルから作ったテスト用コピーをChromeに読み込む。localhostへの権限追加はそのコピーだけに行う。
- APIサーバーはループバックで起動し、ダミーキーとテスト記事を使う。テスト専用ブラウザープロファイルを毎回用意する。使用中のポートや既存のChromeを流用しない。
- 失敗時にも自分で起動したプロセスを閉じる。画像は Playwright の testInfo.outputPath() で tests/results/e2e 以下に保存する。
- [確認コマンド](../docs/others/index.md)から、対象に応じてユニット・カバレッジ・E2Eを実行する。疑似APIで確認できた内容と、実際の提供元に依存する内容を分けて報告する。
